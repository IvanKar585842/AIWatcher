# Phase 12 — готовность к продакшену

Вердикт: **BLOCKED** для выкладки на watchflowing.com.

Код собирается, локальная база содержит нужные таблицы. Боевую базу этот шаг не менял и не проверял. Пока оператор не применит миграции вручную, этот код на прод класть нельзя: новый Prisma-клиент читает колонки и таблицы, которых там ещё нет, и главная снова ответит, что данные не загрузились.

## Что нельзя делать при выкладке

- Не переключать `vercel.json` `buildCommand` на `npm run vercel-build`. Сейчас сборка — `npm run build`: `prisma generate` и `next build`, без `migrate deploy`. Так и должно остаться. Упавшая миграция на Hobby роняет весь деплой.
- Не запускать `prisma db push` на боевой базе.
- Не считать ежедневный cron поминутными проверками.

## Что оператор применяет до деплоя

На боевой базе, отдельной командой `prisma migrate deploy`, в этом порядке:

1. `20261108100000_product_access` — команда, API-ключи, webhook.
2. `20261113160000_workspace_client` — Workspace, Client, связи монитора.
3. `20261113180000_workspace_membership` — роли и приглашения.
4. `20261114130000_site_sdk` — ключ скрипта и сигналы.
5. `20261114140000_domain_verification` — подтверждение домена.

Локальная база собиралась через `db push` и отдельные SQL-файлы, поэтому строка в `_prisma_migrations` сама по себе ничего не доказывает. `scripts/production-preflight.ts` смотрит сами таблицы и колонки и печатает этот список. Строку подключения он не печатает.

## Ритм проверок

- Vercel Hobby: `/api/cron/monitoring` раз в сутки, `0 6 * * *`.
- GitHub Actions каждые 5 минут вызывает прод только если в секретах репозитория есть `CRON_SECRET`. Если секрета нет, шаг завершается успешно и проверки не делает.
- Интервал в 1 минуту требует отдельный worker и `MONITOR_WORKER_URL`.
- Экран биллинга уже показывает фактический ритм, а не обещание тарифа.

## Живые алерты

В этой фазе письма, Telegram и Stripe не отправлялись и не проверялись на бою. В приложении уведомление сохраняется. Почта ждёт Resend, Telegram ждёт токен бота, оплата ждёт боевые ключи Stripe. Эти значения живут на Vercel, здесь они не читались.

## Что уже можно выкладывать только после миграций

Сборка `npm run build` проходит. После ручных миграций тот же `buildCommand` можно деплоить как раньше. Автоматический migrate на сборке не включён. `scripts/production-preflight.ts` на локальной базе прошёл и напечатал те же пять миграций.
