# Phase 8 — отчёты по клиентам

Вердикт: **PASS**

Фаза показывает отчёт по одному клиенту за неделю или месяц и позволяет поставить название агентства. Недельный отчёт всего аккаунта, почта, Telegram, AI-провайдер, загрузка страниц и планировщик не менялись. Новых таблиц нет. Продакшен-база не мигрировалась.

## Что сделано

- Отчёт берёт только мониторы этого клиента в этом workspace. Чужой клиент и чужой workspace отвечают 404. Зритель может читать отчёт.
- Неделя — последние 7 дней, месяц — последние 30. Похожие изменения складываются, как в фазе 7. В ответе нет HTML страницы.
- Название бренда и скрытие строки Powered by Watchflowing живут в уже существующем поле `Workspace.settings`. Переименование workspace от этого не происходит.
- Менять бренд могут владелец и администратор. Участник и зритель получают 404.
- В настройках выбранный клиент показывает период, числа и строки отчёта.

## Доступ

Отчёт не доверяет id клиента без проверки workspace. Бренд не принимает адрес картинки, чтобы отчёт не ходил по чужому URL.

## Проверки

`scripts/test-client-reports.ts` прошёл: только сайты клиента, неделя без старого изменения, месяц со старым, склейка похожих цен, отказ чужому, участник не меняет бренд, бренд не переименовывает workspace, example.com не привязан. `npm run build` прошёл.

В браузере у Acme Studio открылся недельный отчёт с названием North Reports и строкой Powered by Watchflowing. После проверки название бренда снято, workspace по-прежнему называется North Agency.
